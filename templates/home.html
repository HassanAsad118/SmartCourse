SmartCourse AI Recommendation System

AI-powered course recommendation using TF-IDF and Neural Networks

SmartCourse accepts natural language queries and recommends relevant online courses using two independent NLP models. Users can compare keyword-based TF-IDF retrieval against semantic neural embeddings side by side to understand how each model interprets their intent.

Start Recommendation Technical Documentation
System Capabilities
Model 1
TF-IDF Model

Keyword-based retrieval using TF-IDF vectorization with unigram and bigram features. Effective for direct, specific queries where exact terminology matters.

Model 2
Neural Model

Semantic understanding via all-MiniLM-L6-v2 Sentence Transformers. Matches courses by meaning, not just keywords, handling broad or conceptual queries.

Feature
Model Comparison

Run both models on the same query simultaneously and view TF-IDF and Neural results side by side to compare how each model interprets user intent.

Feature
Dashboard

View complete search history with timestamps, save preferred course recommendations, and revisit past queries with one-click model comparison.
